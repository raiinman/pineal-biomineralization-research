## Linking discipline

Concept notes may contain exploratory connections, but durable factual statements should point to canonical project objects:

- `P####` — source/paper
- `C###` — atomic claim
- `H###` — hypothesis
- `E###` — experiment
- `RQ###` — active research question
- `A###` — audit/correction

## Obsidian use

Clone this repository locally and open the repository root as the Obsidian vault. Do not make a separate copy of these notes.
