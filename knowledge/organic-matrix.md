# Organic Matrix

## Central question
What molecular scaffold organizes the organic component of pineal acervuli and does it require active maintenance?

## Evidence state
Class-level evidence for an organic component is strong; exact molecular identity remains incomplete.

## Leading candidates
- [RS1 / Retinoschisin](rs1-retinoschisin.md) — strongest specific perturbation evidence for pineal mineral architecture (`P0009`, `C008`).
- [IMPG2 / SPACRCAN](impg2-spacrcan.md) — pinealocyte-derived HA-binding chondroitin proteoglycan; direct human acervulus localization not found (`P0004`, `C006`, `C007`).
- protease / ECM balance, including the `Serpina1` signal highlighted in `P0005`.

## Working connection to regression
If mature mineral depends on continuing matrix organization, sympathetic denervation could destabilize the organic-mineral interface before visible mineral loss.
