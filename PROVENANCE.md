# Reconstruction Provenance

> **Repository role:** Defines how primary literature, saved artifacts, recovered conversations, and reconstructed history are distinguished so evidence provenance stays auditable.

The repository combines three kinds of source material:

1. **Primary scientific literature** — papers, abstracts, datasets, archival scans.
2. **Saved project artifacts** — cross-reference prompts, audit reports, pasted research summaries and figures created during the project.
3. **Conversation reconstruction** — chronology recovered from the project history when an exact turn-by-turn transcript is not stored as a repository artifact.

## Historical reconstruction rule

A reconstructed statement about the project's own history is not the same thing as a scientific claim about pineal biology.

Each historical assertion should be treated as one of:
- **EXACT ARTIFACT** — preserved image/text/file exists;
- **DIRECT CONVERSATION RECORD** — exact prior message is recoverable;
- **RECONSTRUCTED FROM PROJECT NOTES** — strongly supported by later saved summaries but exact original wording may be unavailable;
- **UNCERTAIN ORDER** — topic is known to have occurred but sequence/date is not fully recoverable.

## Scientific provenance rule

For biological/mineral claims, repository notes should always distinguish:
- human vs animal;
- pineal vs imported non-pineal mechanism;
- primary paper vs review;
- exact replication vs conceptual/partial replication;
- direct observation vs mechanistic inference;
- materials chemistry vs in-vivo physiology.

## Known correction preserved

An earlier project audit attributed adult SCGx-induced concretion regression to Welsh/Beitz/Welsh-era work. Later forensic reconstruction identified **Champney et al. 1985** as the key adult established-concretion loss experiment, while **Reiter, Welsh & Vaughan 1976** is the juvenile formation-prevention experiment.

This is precisely why provenance and citation-chain auditing are mandatory in the repository.
