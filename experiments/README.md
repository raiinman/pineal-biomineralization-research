# Proposed Experiments

> **Repository role:** Converts unresolved hypotheses into concrete experiments capable of confirming, narrowing, or falsifying them.

## Current designs

- `E001-modern-champney-replication.md` — longitudinally test whether pre-existing adult concretions truly lose mineral after SCGx.
- `E002-impg2-acervuli-localization.md` — directly test whether IMPG2/SPACRCAN is spatially associated with human acervuli.
- `E003-rs1-after-scgx.md` — test whether RS1 changes before post-SCGx concretion loss.

## Standard

Every proposed experiment should state the question, design, critical readouts, and what result would materially change the working model.
