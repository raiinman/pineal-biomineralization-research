# E003 — RS1 Response After Adult SCGx

> **Repository role:** Defines a time-resolved experiment to test whether RS1 changes before the adult post-SCGx concretion-loss phenotype appears.

## Question
Does sympathetic denervation alter RS1 before concretion loss becomes visible?

## Time course
Hours → days → 2 weeks → 12 weeks.

## Readouts
- Rs1 mRNA
- RS1 protein abundance
- extracellular vs intracellular localization
- oligomeric state if feasible
- connexin-36 spatial association
- calcified spot/nodule architecture
- microvesicular mineral accumulation

## Interpretation
A reproducible early RS1 change preceding mineral regression would create a direct molecular bridge between Champney and the 2024 RS1 phenotype.
