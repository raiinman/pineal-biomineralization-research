# Hypotheses

> **Repository role:** Holds explicit, falsifiable mechanistic hypotheses so individual ideas can be strengthened, weakened, or rejected independently.

## Standard

Each hypothesis must include its evidence basis, prediction, current confidence, and a result that would weaken or falsify it.
