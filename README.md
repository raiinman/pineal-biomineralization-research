<a name="readme-three-layer-stack"></a>
## Three-layer stack


**Zotero = source library** — PDFs, bibliographic metadata, annotations.  
**This repository = scientific record** — claims, hypotheses, audits, experiments, data/code.  
**Obsidian = optional interface over this repository** — when used locally, open the repository folder itself as the Obsidian vault rather than creating an independent research copy.

GitHub Issues carry the active `RQ###` research queue. A GitHub Project can provide a visual board over those Issues without becoming a second task database.

<a name="readme-core-scientific-question-now"></a>
## Core scientific question now


**What is pineal calcification made of, how does it form, and can an already mature pineal acervulus naturally lose mineral or regress?**

The project deliberately separates:

<table align="center"><tbody><tr><td align="center">1</td><td align="center"><strong>Formation / prevention</strong> — nucleation and growth of new mineral.</td></tr><tr><td align="center">2</td><td align="center"><strong>Mature-deposit regression</strong> — loss, fragmentation, dissolution, or clearance of established mineral.</td></tr></tbody></table>


These processes are not interchangeable.

<p align="center"><a href="#readme-index">↑ Back to index</a></p>

<a name="readme-current-working-model"></a>
## Current working model


The strongest current model treats a mature pineal acervulus as a **heterogeneous, laminated, organically structured calcium-phosphate biomineral** rather than a passive inert stone.

Key active research branches:

<table align="center"><tbody><tr><td align="center">sympathetic / adrenergic control</td></tr><tr><td align="center">intracellular Ca/P precursor handling</td></tr><tr><td align="center">extracellular-matrix organization</td></tr><tr><td align="center">RS1 / retinoschisin</td></tr><tr><td align="center">IMPG2 / SPACRCAN</td></tr><tr><td align="center">microglial response and mineral-fragment clearance</td></tr><tr><td align="center">human acervulus destruction morphology</td></tr><tr><td align="center">ex-vivo hydroxyapatite dissolution chemistry</td></tr></tbody></table>

<a name="readme-research-rules"></a>
## Research rules


<p align="center"><em><strong>No important conclusion should exist only in a chat.</strong></em></p>


Every material finding should be promoted into the appropriate durable objects: paper dossier, claim, pathway/hypothesis, experiment, audit, and research log.

<p align="center"><em><strong>Failed hypotheses are archived, not erased.</strong></em></p>


<p align="center"><em><strong>A search result is not a paper, a review is not an exact replication, and animal pineal evidence is not human pineal proof.</strong></em></p>
