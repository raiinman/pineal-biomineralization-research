# Pineal Biomineralization Research

A version-controlled research ledger for the scientific investigation of pineal calcification, acervuli, biomineralization, and mature-deposit regression.

## Core question

**What is pineal calcification made of, how does it form, and can an already mature pineal acervulus naturally lose mineral or regress?**

The project deliberately separates:

1. **Formation / prevention** — nucleation and growth of new mineral.
2. **Mature-deposit regression** — loss, fragmentation, dissolution, or clearance of established mineral.

These processes are not interchangeable.

## Current working model

The strongest current model treats a mature pineal acervulus as a **heterogeneous, laminated, organically structured calcium-phosphate biomineral** rather than a passive inert stone.

Key active research branches:

- sympathetic / adrenergic control
- intracellular Ca/P precursor handling
- extracellular-matrix organization
- RS1 / retinoschisin
- IMPG2 / SPACRCAN
- microglial response and mineral-fragment clearance
- human acervulus destruction morphology
- ex-vivo hydroxyapatite dissolution chemistry
